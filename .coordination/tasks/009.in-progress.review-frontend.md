## Acceptance criteria (verify and report)
- [ ] **Single source of truth:** `Login.jsx` and `AnonymousSignup.jsx` import the validators from
      `src/utils/validation.js` — no re-invented inline regex/length checks remain in either form
      (the cosmetic strength meter in AnonymousSignup may remain, but only as display).
- [ ] **Canonical messages match backend:** the strings returned by `validation.js` are
      character-for-character identical to the backend `ArgumentException` messages and the Shared
      Contract table in `.coordination/PLAN.md`.
- [ ] **HIBP soft-check:** `pwnedService.js` uses the external host directly (NOT `API_BASE_URL`),
      uppercases the SHA-1 hex prefix, and returns `'unknown'` (fail open) on network error; forms
      only block on `'breached'`.
- [ ] **Stuck-button bug fixed:** in `Login.jsx`, `setIsSubmitting(true)` no longer runs before the
      validation early-returns; a failed validation leaves the button clickable.
- [ ] **Login path has NO strength gate:** org login and anonymous login only check fields-present;
      `validatePassword`/`checkPwned` are not called on login.
- [ ] **No network call on client-invalid input:** malformed email / weak password / bad username
      block submit before any `fetch`.
- [ ] **Defect fixes:** `systemUserService.js` line 1 is `http://127.0.0.1:80` (not `https`);
      `AnonymousLogin.jsx` has zero `alert(` calls and uses the inline error block.
- [ ] **Honest helper text:** `Login.jsx` signup helper text reflects the real rule (incl. lowercase).
- [ ] **No scope creep:** AuthContext, routing, and `localStorage` token storage untouched.
- [ ] `npm run build` succeeds (run it).
