# Task 010: guide-service-catalog

**Type:** both
**Dependencies:** 001

## Goal
Write `.claude/guides/service-catalog.md` — the per-service reference: for each of the 11
services, its controllers (→ routes), key entities/models, and the repositories. This is the
"where do I go to change X" lookup table.

## Acceptance criteria
- [ ] File `.claude/guides/service-catalog.md` created.
- [ ] "Sources" section lists files/dirs read (listing controllers/models per service is fine
      via directory reads — name the dirs).
- [ ] One subsection per service (all 11) with three compact tables or lists:
      - Controllers → route prefix (`api/[controller]`) and the key actions.
      - Key entities (model class names under `Models/`).
      - Repositories (`IXxxRepository` pairs under `Data/`).
- [ ] Note cross-service entities each service owns vs duplicates (e.g. `SuggestionService`
      has its own copies of `AnonymousUser`, `BoxAccessLink`, `Attachment` models in the
      `AnonymousDomain` namespace — flag these as duplicated, not authoritative).
- [ ] Keep it scannable — tables, not prose. Do NOT enumerate every DTO; entities + controllers only.

## Context
- Enumerate per service: `find <Service> -name "*.cs" -path "*Controllers*"`,
  `... -path "*Models*"` (exclude `DTOs`), `... -path "*Data*"`.
- Confirmed controller inventory (from scan): AnonymousUser, BoxAccessLink (AnonymousUserService);
  Organization, User, UserRole (OrganizationService); Problem, ProblemCategory, ProblemComment
  (ProblemService); ProblemBox (ProblemBoxService); Suggestion, SuggestionCategory,
  SuggestionComment, Vote (SuggestionService); SuggestionBox (SuggestionBoxService);
  Subscription, SubscriptionPlan, Payment (SubscriptionService); BillingNotification;
  SystemNotification; Attachment; Logger.
- Read enough of 2-3 controllers per service to capture the key actions (don't read all).
- Duplicated models evidence: `grep -rl "namespace AnonymousDomain"` → 20 files; note which
  services hold copies (SuggestionService notably has AnonymousUser.cs, BoxAccessLink.cs, Attachment.cs).
- Cross-link guide 011 (contracts) for who-calls-whom; this guide is the static catalog.

## Solution

Created `.claude/guides/service-catalog.md` with one subsection per all 11 services, each containing controller/route/action tables, key entity lists, and `IXxxRepository`↔`XxxRepository` pairs, plus a cross-service AnonymousDomain duplication summary flagging `SuggestionService` (8 duplicated model files), `BillingNotificationService`, and `SystemNotificationService` as holders of non-authoritative `AnonymousDomain.*` copies.
