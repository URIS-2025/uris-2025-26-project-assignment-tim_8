# Task 003: rule-repositories-and-dtos

**Type:** code
**Dependencies:** 001

## Goal
Write `.claude/rules/repositories-and-dtos.md` — the data-access + DTO contract:
repository interface/impl pairs registered scoped, `SaveChanges()` returning `bool`,
manual `IMapper.Map` mapping, validation-and-throw inside repos, and the DTO/VO naming
convention. Entities are NEVER returned from controllers.
