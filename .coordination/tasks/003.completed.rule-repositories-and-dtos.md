## Solution

The repository-and-DTO layer is fully consistent across all 11 services: every repository is registered `AddScoped`, exposes `public bool SaveChanges() => _context.SaveChanges() > 0`, maps all entities to DTOs via `_mapper.Map` (never returning raw EF types), sets `Id` and `CreatedAt` in the repo on create, and throws typed exceptions for validation failures — with the documented gotcha that "not found" uses `ArgumentException` in most repos but `KeyNotFoundException` in `AnonymousUserRepository`.
