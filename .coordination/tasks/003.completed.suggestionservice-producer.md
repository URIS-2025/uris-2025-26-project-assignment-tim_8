# Task 003: SuggestionService Notification Producer (Agent B)

**Type:** code
**Dependencies:** 001

## Goal
Make SuggestionService produce a **system notification** on three events: (a) a new suggestion submitted, (b) a new suggestion comment (any author), and (c) a new vote on a suggestion. Resolve the owning `organizationId` via `SuggestionBoxService`, then fire a non-fatal notification call forwarding the caller's JWT. Add unit tests.

## Acceptance criteria
- [ ] New suggestion submitted → one system notification with resolved `OrganizationId` + sensible `Text`.
- [ ] New suggestion comment → one system notification with resolved `OrganizationId`, `SuggestionCommentId` set, sensible `Text`.
- [ ] New vote → one system notification with resolved `OrganizationId` + sensible `Text` (e.g. "A suggestion received a new vote.").
- [ ] Org-id resolved via `GET api/SuggestionBox/{boxId}` → `OrganizationId`. Box lookup failure/null → notification skipped, underlying create still succeeds (no throw).
- [ ] Notification call non-fatal (task 001 contract); caller's `Authorization` header forwarded to box lookup + notification call.
- [ ] Named `HttpClient`s for `SuggestionBoxService` and `SystemNotificationService` registered in `Program.cs`; URLs in `appsettings.json` `Services` section.
- [ ] Unit tests (xUnit + Moq, in `SuggestionServiceTests/`): notification client called once per event with correct resolved org-id; box-missing → no notification + no throw; notification-client-throws → underlying create still succeeds; vote path covered.
- [ ] `dotnet build` and the SuggestionService tests pass.

## Findings / Solution

SuggestionService now produces a **system notification** on three events — new suggestion,
new suggestion comment, and new vote — following the task 001 contract.

**New files (`SuggestionService/Clients/`):**
- `SystemNotificationCreationDTO.cs` — local DTO copy (`Text`, `OrganizationId?`,
  `AnonymousUserId?`, `ProblemCommentId?`, `SuggestionCommentId?`).
- `SystemNotificationServiceClient.cs` — non-fatal `virtual TryNotifyAsync(dto, bearer, ct)`,
  `POST /api/SystemNotification`, try/catch-swallow + 800 ms timeout (mirrors
  `LoggerServiceClient`). Parameterless ctor + `virtual` so it's Moq-able.
- `SuggestionBoxServiceClient.cs` — non-fatal `virtual Task<Guid?> TryGetOrganizationIdAsync(
  boxId, bearer, ct)`, `GET /api/SuggestionBox/{id}`, returns `null` on missing/non-2xx/error.
- `SuggestionBoxVO.cs` — minimal projection exposing `OrganizationId`.

**Controllers (all in `AnonymousAPI.Controllers`):**
- `SuggestionController.CreateSuggestion` → `NotifySuggestionSubmittedAsync`: org from
  `result.SuggestionBoxId`, `Text="A new suggestion was submitted."`.
- `SuggestionCommentController.CreateSuggestionComment` → `NotifyCommentCreatedAsync`:
  inject `ISuggestionRepository`, resolve `result.SuggestionId` → `GetById().SuggestionBoxId`
  → box → org, `Text="A new comment was added to a suggestion."`, `SuggestionCommentId=result.Id`.
- `VoteController.CreateVote` → `NotifyVoteCreatedAsync`: inject `ISuggestionRepository`,
  resolve `result.SuggestionId` → suggestion → box → org, `Text="A suggestion received a new vote."`.
- All three skip silently when the suggestion/box is unresolvable; each forwards the caller's
  `Request.Headers["Authorization"]` to both box lookup and notification; each helper is itself
  wrapped in try/catch.

**Wiring:**
- `Program.cs`: registered scoped `SystemNotificationServiceClient` + `SuggestionBoxServiceClient`
  and named HttpClients `"SystemNotificationService"` / `"SuggestionBoxService"`.
- `appsettings.json` `Services`: `SystemNotificationService=http://system-notification-service:8080/`,
  `SuggestionBoxService=http://suggestion-box-service:8080/`.

**Tests** (`SuggestionServiceTests/` — the project wired into `AnonymousApp.sln`):
- New `NotificationProducerTests.cs`: 8 tests — per controller, notification sent once with
  resolved org-id (and `SuggestionCommentId` for comments); box-missing → `Times.Never` + still
  `Created`; suggestion + vote also cover notification-throws → still `Created`. Clients mocked
  via `virtual`; `DefaultHttpContext` supplied so `Request.Headers`/`User` resolve.
- Updated `SuggestionTests.cs` existing controller-test ctors (Suggestion/Comment/Vote) for the
  new client params (+ `ISuggestionRepository` for comment/vote).

**Verification:** `dotnet build SuggestionService` and `dotnet build SuggestionServiceTests` →
0 errors. `dotnet test` (non-integration filter) → **49 passed, 0 failed**.
