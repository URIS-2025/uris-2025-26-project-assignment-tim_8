# Task 007: frontend-defect-fixes

**Type:** code
**Dependencies:** none

## Goal
Two independent frontend defect fixes called out in the plan: replace `alert()` in the anonymous
login with the inline error block used everywhere else, and fix the broken `https://` gateway URL
in `systemUserService.js`. No dependency on the shared validator — can run in parallel from the start.

## Acceptance criteria
- [ ] `Frontend/reporting-app/src/services/systemUserService.js:1`: change
      `const API_BASE_URL = 'https://127.0.0.1:80';` → `const API_BASE_URL = 'http://127.0.0.1:80';`
      (the gateway is plain HTTP; `https` is currently broken). Match the exact string used by the
      other services (`http://127.0.0.1:80`).
- [ ] `Frontend/reporting-app/src/pages/AnonymousLogin.jsx`: replace BOTH `alert()` calls (currently
      at `:20` "Please fill in all fields." and `:44` `error.message || 'Login failed...'`) with the
      inline error-block pattern used elsewhere:
  - Add `const [error, setError] = useState('');` to component state.
  - On the "all fields" guard → `setError('Please fill in all fields.')` + return (no alert).
  - In the catch → `setError(err.message || 'Login failed. Please try again.')` (no alert).
  - `setError('')` at the start of submit.
  - Render the same inline error block markup used in `AnonymousSignup.jsx:75-85` / `Login.jsx:174-184`
    (flex div, `rgba(239,68,68,...)` styling, `<AlertCircle size={16} />` + `<span>{error}</span>`),
    placed above the form. Import `AlertCircle` from `lucide-react` if not already imported.
- [ ] Login path: do NOT add any password-strength validation (login only needs the fields-present
      guard — existing users may predate the policy).
- [ ] `npm run build` succeeds; no remaining `alert(` calls in `AnonymousLogin.jsx`.
