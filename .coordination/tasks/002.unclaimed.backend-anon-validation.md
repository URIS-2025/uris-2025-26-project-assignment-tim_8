## Context
- **Why depend on 001:** the two shared files MUST stay byte-identical across services (no shared
  project — matches the existing `AnonymousDomain` duplication reality). Copying 001's actual
  committed files guarantees that; do not re-derive them from scratch.
- **Controller error mapping today:** `AnonymousUserController.Create` only handles 409. Without the
  new `ArgumentException` catch, a validation throw bubbles to the global handler (wrong shape
  `{ message }` / 500). This is the single most important fix in this task — verify with curl.
- **Anonymous users have NO email.** Only username + password are validated. The username rule is
  `^[a-zA-Z0-9_]+$`, length 3–30.
- **DTO:** `AnonymousUserService/Models/DTOs/AnonymousUser/AnonymousUserCreationDTO.cs` has
  `Username` + `Password`.
- Same repo/Clients conventions as Task 001 (see that file). Rate limiting unchanged
  (`[EnableRateLimiting("register")]` already present).
