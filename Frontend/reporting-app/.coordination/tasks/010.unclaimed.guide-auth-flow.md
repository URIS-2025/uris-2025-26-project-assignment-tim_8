Flow to document:
1. User submits credentials → a service `login()` returns `{accessToken, refreshToken}`.
2. `AuthContext.login()` decodes the access token (`jwtDecode`), reads claims by
   `http://schemas.xmlsoap.org/ws/2005/05/identity/claims/*` URIs + `RoleId`.
3. Role title fetched via `UserRoleService.getById(roleId)`, lowercased; default `'user'`.
4. Persisted to `localStorage` (`authUser` JSON + `authToken` raw). Services read `authToken`.
5. On app init (`useEffect`), expired token → `silentRefresh` → POST `/api/User/refresh`
   (org, has `roleId`) or `/api/AnonymousUser/refresh` (anonymous, no `roleId`). Failure → `logout()`.
6. `ProtectedRoute` gates `/admin/*`: no user → `/login`; wrong role → `/admin/dashboard`.

Gotchas: anonymous identity is distinguished purely by absence of `roleId`; tokens live in
localStorage (XSS surface); role name normalization is lowercase string compare.
