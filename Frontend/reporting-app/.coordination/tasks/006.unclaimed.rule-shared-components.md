# Task 006: Rule — shared components (DataTable, Modal, StatusBadge)

**Type:** code
**Dependencies:** 001

## Goal
Write `.claude/rules/shared-components.md` covering the reusable components and their prop
contracts so agents wire them correctly instead of re-rolling tables/modals.

## Acceptance criteria
- [ ] File ≤500 lines, table-heavy, WRONG/CORRECT pairs.
- [ ] ≥3 real `file:line` occurrences cited (which pages use each component).
- [ ] Uses real names: `DataTable`, `Modal`, `StatusBadge`, `Navbar`, `Sidebar`, and real props (`columns`, `data`, `onRowClick`, `render`, `accessor`).
- [ ] Documents `DataTable` config-driven `columns` ({header, accessor, render, align, width}) and pagination props.

## Context

Read: `src/components/DataTable.jsx` (165 lines), `src/components/Modal.jsx`, `src/components/StatusBadge.jsx`,

Confirmed (planner scan):
- `DataTable` props: `title, data, columns, onRowClick, onActionClick, searchPlaceholder, showExport,
  searchValue, onSearchChange, currentPage, onPageChange, pageSize=5`. Columns are objects with
  `header`, `accessor` (or `render(row)`), optional `align`/`width`. Pagination activates only when

- `DataTable` used by 6 pages: `BoxDetails`, `BoxSettings`, `OrganizationDetails`, `ProblemBoxes`,
  `SuggestionBoxes`, `UserManagement`.
- `Modal` used by 7 pages: `AdminDashboard`, `BoxSettings`, `OrganizationDetails`, `ProblemBoxes`,
  `SubscriptionDetails`, `SuggestionBoxes`, `UserManagement`.
- Icons come from `lucide-react` (24 files import it) — confirm Modal/StatusBadge prop shapes by reading them.

Rule content (WRONG/CORRECT):
- Tabular admin data → use `DataTable` with a `columns` config, not a hand-rolled `<table>`.
- Custom cell content → use `column.render(row)`, not raw JSX in the page.
- Status pills → use `StatusBadge`, not inline colored spans.
- Icons → import from `lucide-react`.
