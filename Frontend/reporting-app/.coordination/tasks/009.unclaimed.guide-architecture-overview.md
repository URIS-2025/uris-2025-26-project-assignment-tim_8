Key facts to convey:

- Layered structure: `pages/` (screens) → `services/` (fetch wrappers) → backend via Nginx gateway.
- All API calls target `http://127.0.0.1:80/api/*`; backend services are NOT individually exposed —

- Commands: `npm install`, `npm start` (:3000), `npm test`, `npm run build`.
- Gotcha: dev server is :3000 but API base is hardcoded `http://127.0.0.1:80` in every service +
  `AuthContext`. No `.env` / proxy indirection.
