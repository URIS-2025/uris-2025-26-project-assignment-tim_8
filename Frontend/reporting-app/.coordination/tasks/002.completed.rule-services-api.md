# Task 002: Rule — service / API layer

**Type:** code
**Dependencies:** 001

## Goal
Write `.claude/rules/services-api.md` documenting how to write and call the
`src/services/*.js` modules: the plain-object export pattern, `API_BASE_URL` constant,
raw `fetch` + `if (!response.ok) throw new Error(...)`, and the auth-header gap.

## Acceptance criteria
- [ ] File ≤500 lines, table-heavy, WRONG/CORRECT code pairs.
- [ ] Findings section cites ≥3 real `file:line` occurrences for each documented pattern.
- [ ] Uses real names: `ProblemService`, `AnonymousUserService`, `getAuthHeader`, `extractErrorMessage`.
- [ ] Documents the inconsistency: most services do NOT attach auth headers; `anonymousUserService.js` defines `getAuthHeader()`/`extractErrorMessage()`.
- [ ] Repo-relative paths only.

## Context
Read first: `.coordination/SCAN_REPORT.md`.
Read these files: `src/services/problemService.js`, `src/services/anonymousUserService.js`,
plus 2–3 others (`organizationService.js`, `suggestionService.js`, `voteService.js`) to confirm the shape.

Confirmed pattern (planner scan):
- Every module starts `const API_BASE_URL = 'http://127.0.0.1:80';`
- Exports a frozen-style plain object: `export const ProblemService = { getAll, getById, create, update, delete }`
- Methods are `async`, return `await response.json()` (or `true` for delete), and throw on `!response.ok`.
- POST/PUT/DELETE base path uses a trailing slash (`/api/Problem/`); GET-by-id appends `${id}` (no trailing slash).
- Error handling: simple `throw new Error('Failed to ...')` in most; `anonymousUserService.js` adds
  `extractErrorMessage(response)` (parses `data.errors`/`data.error`/`data.title`) and `getAuthHeader()`.

Rule content to capture (WRONG/CORRECT):
- Adding a new resource → mirror existing module shape, not a class or axios.
- Don't hardcode the URL inline in components; call through a service module.
- When to attach `getAuthHeader()` (authenticated endpoints) vs not.
- Throwing on `!response.ok` is mandatory so pages' try/catch sets error state.

- `grep -rn "export const .*Service = {" src/services`
- `grep -rn "if (!response.ok) throw" src/services`
- `grep -rln "getAuthHeader\|extractErrorMessage" src/services`
