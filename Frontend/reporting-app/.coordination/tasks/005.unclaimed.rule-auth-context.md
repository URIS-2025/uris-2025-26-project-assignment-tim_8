# Task 005: Rule — auth context & token handling

**Type:** code
**Dependencies:** 001

## Goal
Write `.claude/rules/auth-context.md` covering how to use auth on the frontend: `useAuth()`,
the localStorage keys, role resolution, and token/refresh handling — without re-implementing it.

## Acceptance criteria
- [ ] File ≤500 lines, table-heavy, WRONG/CORRECT pairs.
- [ ] ≥3 real `file:line` occurrences cited.
- [ ] Uses real names: `AuthProvider`, `useAuth`, `login`, `logout`, `silentRefresh`, `authUser`, `authToken`, `UserRoleService.getById`.
- [ ] Documents JWT claim keys (the `http://schemas.xmlsoap.org/...` nameidentifier/emailaddress, `RoleId`) and role lowercase normalization.

## Context
Read first: `.coordination/SCAN_REPORT.md`.
Read: `src/context/AuthContext.js` (whole file, 146 lines), and one consumer e.g. `src/pages/Login.jsx`.

Confirmed (planner scan):
- Single provider `AuthProvider` exposes `{ user, login, logout }` via `useAuth()`.
- `login(loginResponse)` accepts `{accessToken, refreshToken}` OR a bare token string
  (`loginResponse?.accessToken ?? loginResponse`), decodes via `jwtDecode`, reads claims by the
  long `http://schemas.xmlsoap.org/...` URIs + `RoleId`, fetches role title via
  `UserRoleService.getById(roleId)`, lowercases it (default `'user'`).
- Persistence: `localStorage` keys `authUser` (JSON blob incl. token) and `authToken` (raw token).
  Services read the token from `localStorage.getItem('authToken')`.
- `isTokenExpired` checks `exp*1000 < Date.now()`. On init, expired token → `silentRefresh`
  (POST `/api/User/refresh` or `/api/AnonymousUser/refresh` depending on `roleId` presence) → else `logout()`.

Rule content (WRONG/CORRECT):
- Read auth via `useAuth()`, never parse localStorage in components directly (except token in services).
- New login flow → call `login(response)`; don't set `authUser`/`authToken` manually.
- Roles are lowercase strings (`'admin'`, `'manager'`, `'user'`); compare lowercased.
- Anonymous users have no `roleId` → that's how refresh endpoint is chosen.

Evidence greps:
- `grep -rn "useAuth\|AuthProvider" src`
- `grep -rn "localStorage.getItem('authToken')\|localStorage.setItem('authUser'" src`
- `grep -rn "jwtDecode\|RoleId\|silentRefresh" src/context/AuthContext.js`
